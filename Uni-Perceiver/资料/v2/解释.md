# Uni-Perceiver v2 论文与实现边界解释

## 1. 论文版本与材料

本地 [原论文](原论文.pdf) 为 arXiv:2211.09808v1，2022-11-17，14 页；[中文论文](中文论文.pdf) 和 [双语论文](双语论文.pdf) 已由 pdf2zh/API 生成，首页摘要漏译修复后已经视觉核对，全文仍需审校。本文解释以本地 v1 为准，不将 CVPR 后续版不同数字混入。

前序阅读：[原版](../../解释.md)、[MoE](../MoE/解释.md)。v2 继承候选匹配与属性 MoE，但增加可定位区域表示、现成模态编码器和多任务优化策略。

## 2. 问题与贡献【必须会】

原版用固定 patch 表示图片，擅长整体匹配，却缺少直接输出对象位置和形状的结构。v2 希望同时处理图像分类、检测、实例分割、图文检索、图像描述等任务，并在联合训练后使用共享模型直接评价。

核心变化：图片表示包含全局特征与区域提案；文字使用预训练 RoBERTa；共享 Transformer 将不同任务转为候选匹配；检测/分割保留区域的框和 mask；训练采用整轮只选一个任务的采样和 MT-AdamW。

“无任务特定适配”指联合训练完成后不再为每个评价任务独立微调，不表示没有这些任务的训练数据。COCO 检测/分割与 ImageNet 分类本身参与训练。Flickr30k 没有参与联合训练，才是相应迁移评价。

表 1 的任务类别是研究目标范围，不表示所有列出的任务都有实验证据。图像合成明确因资源限制未验证，不能宣称 v2 已复现所有视觉输出。

## 3. 方法地图与图 3【必须会】

`图片 → 多尺度 backbone → 区域提案网络 + 全局池化 → 全局/区域 token`。

`文字 → BPE/token embedding → RoBERTa → 文字 token`。

`输入/候选表示 → 插入 SPE → 共享 decoder g → 余弦相似度/候选概率 → 任务结果`。

backbone=骨干；proposal=候选区域提案；objectness=是否像前景对象的分数；semantic=语义；bbox=bounding box（边界框）；mask=对象像素区域；decoder=解码/任务适配网络。本篇 decoder 是共享表示变换，不应只因名字就认为所有任务都逐词自回归生成。

区域提案网络先预测对象存在、框和像素 mask；最终区域类别由共享 decoder 特征与类别文字匹配。框/mask 的中间监督也存在，因此“统一目标”不能解释为训练中绝对没有任何额外检测损失。

## 4. 式 1：全局加区域【必须会】

\[
f_{image}(x)=\operatorname{Concat}(\{q_i^{global}\}_{i=1}^{M},\{q_j^{proposal}\}_{j=1}^{N}).
\]

x 是图片；global 是全图表示，proposal 是区域表示；各 token 宽度统一为 d。若组批后全局 `[B,M,d]`、区域 `[B,N,d]`，沿 token 轴 concat 得 `[B,M+N,d]`。它不是把特征宽度拼成 2d。

论文正文及附录对候选数量符号使用并不完全统一：附录以 N 表示最初 300/900 个查询，以 O 表示过滤后 200 个区域。追形状时要按具体阶段说明，不能看到 N 就一律当成 200。

## 5. 式 2/9：区域不仅包含语义【必须会】

\[
q_j^{proposal}=q_j^{sem}+\mathcal B(q_j^{box})+\mathcal M(q_j^{mask}).
\]

sem=semantic，表示“是什么”；box 是四个坐标，表示“在哪里”；mask 表示区域形状。三个项先投影到相同宽度 d，再逐元素相加。框四维不能直接与 d 维语义相加，必须先编码/投影。

mask 分支先自适应平均池化到 28×28，再投影。28×28=784，描述区域形状；这一步不是把原图输入缩到 28×28，也不是最终输出 mask 一定只有 28×28。

附录明确 box/mask 在融合前 detach：语义融合任务的梯度不会通过这两项的输入继续传回框/mask 预测分支；后续投影仍可训练，区域网络也可由检测监督训练。detach 不是删除这些数值。

## 6. 式 3：全图池化与密集特征【必须会】

\[
q^{global}=\operatorname{Concat}(\{\operatorname{AttnPool}_i(F_L)\}_{i=1}^{M'},\operatorname{Flatten}(F_L)).
\]

F_L 是最后尺度特征图。实际有通道轴，批次形式应理解为 `[B,C,h,w]`，论文简写省略部分维度。flatten 把空间轴变成 h*w 个 token，经必要通道匹配得到 `[B,h*w,d]`。M'=10 组注意力池化提供 10 个全图 token，所以全局 token 数不是只等于 10，还含展平空间特征。

例如末层为 7×7，若通道已投影到 d，则全局 token 数是 10+49=59；再加过滤后 200 个区域得 259。这个例子用于理解公式，并非声称所有分辨率都固定输出 259。

## 7. 附录区域提案流程【建议会】

backbone 输出空间尺度约 H/4、H/8、H/16、H/32。1×1 卷积匹配通道到 256；另用 stride=2 的 3×3 卷积得到 H/64 尺度。区域 Transformer 使用四个尺度（跳过最细尺度），不是只用最后一张图。

deformable attention=可变形注意力，在若干参考位置采样特征，降低多尺度密集注意力成本。根据 objectness 选 top-N 特征，加上可学习 object queries，然后 decoder 预测候选语义/框/mask。

ResNet-50 用 300 个候选查询；Swin 用 900；最后再按 objectness 选 200 个送共享 decoder。top-N 特征选取与最终 top-200 提案过滤是两个阶段，不能合并解释。

附录式 8 的 mask 预测将每个对象的 MLP 向量与每像素特征做通道点积，再上采样。可理解为 `[B,N,d]` 与 `[B,d,h,w]` 得 `[B,N,h,w]`，再恢复目标空间分辨率；这里按通道求和，不是逐元素乘后保留 d 轴。

训练定位任务时还有去噪查询、对象存在二分类、框与 mask 的中间监督；表 7 列出 bbox/GIoU/mask/dice 系数。GIoU=Generalized Intersection over Union，Dice 衡量区域重合，不是分类准确率。

## 8. 文字与共享任务适配【必须会】

式 4 文字编码输出一串 token 特征。BPE=Byte Pair Encoding（字节对编码）；RoBERTa 是改进 BERT 的预训练系列。本篇采用 BASE 并联合微调，不是永久冻结文字编码器。

\[
\hat y=\arg\max_{y\in\mathcal Y}P(x,y),\qquad
P(x,y)\propto\exp\{\cos(g\circ f(x),g\circ f(y))/\tau\}.
\]

f 是模态专用编码器，g 是共享 decoder；组合符号 `g∘f` 表示先 f 再 g。输入可以是图像、文字或组合；候选也进行相同形式的编码。SPE 是特殊表示 token。

分类比较全局输入与类别文字；检索比较图文；caption 对词表预测；检测/实例分割针对各区域输出特征比较类别文字，同时使用该提案的 box/mask 作为位置结果。共享分类匹配并不让所有任务只返回一条句子。

## 9. 式 7：采样与损失权重【必须会】

\[
\mathcal L=\sum_{k=1}^{K}s_k\mathbb E_{(x,y)\in(\mathcal X_k,\mathcal Y_k)}
[-w_k\log(P(x,y)/\sum_{z\in\mathcal Y_k}P(x,z))].
\]

K 是任务数；s_k 是抽样概率且总和为 1；w_k 是损失系数。频繁抽取一个任务和增大它的每次梯度权重，是不同操作。普通联合训练中它们都会影响贡献，所以后续优化器尝试将其解耦。

表 8 总任务概率：分类 0.1、定位 0.25、MLM 0.05、caption 0.3、retrieval 0.3，总和 1。MLM 每 GPU 256 样本、检测每 GPU 1 样本，不意味着两任务贡献按 256:1 计算。

caption/retrieval 内部数据集按规模平方根设权重，降低大数据集垄断。s_k（采样概率）、w_k（目标权重）与后面的 omega_k（规范化梯度缩放）需分别追踪，不能都写成同一个“weight”。

## 10. MT-AdamW 为什么改变矩估计【建议会】

mixed sampling 一轮混合多个任务；unmixed 一轮所有 GPU 使用同一个任务。后者能给检索更大同任务负例批次，但切任务时梯度尺度/方向变化大。

论文先规范化当前任务梯度：

\[
g_t=\omega_k\frac{\nabla L_{t,k}(\theta_{t-1})}{\|\nabla L_{t,k}(\theta_{t-1})\|}.
\]

theta 是参数，t 是优化步，k 是当前任务，omega_k 是该任务贡献缩放。规范化去除原梯度范数差异，但保留方向；零范数时如何保护需看实际实现，论文简式未给出。

论文的矩更新记号是：

\[
m_t=(1-\beta_1)m_{t-1}+\frac{\beta_1}{s_k}g_t,\qquad
n_t=(1-\beta_2)n_{t-1}+\frac{\beta_2}{s_k}g_t^2.
\]

注意这是本地论文写法，beta 的意义与常见 PyTorch Adam 写法的旧状态系数不同，不能照抄典型 beta 数值。二阶项乘 1/s_k，不是将整个 g/s_k 平方导致 1/s_k²。

直觉：任务以概率 s_k 被抽到，当次贡献乘 1/s_k，期望贡献可抵消抽样频率。例如 s=0.1，抽中时乘 10；期望为 0.1×10=1。它不能保证消除所有任务梯度方向冲突，属性 MoE 仍有作用。

参数更新使用 m/(sqrt(n)+epsilon)；论文省略权重衰减与偏差修正，只展示核心改变。epsilon 防小分母，与路由噪声符号用途不同。

## 12. 表 6 与图 2：主结果与公平比较【建议会】

| 模型 | 分类Acc | 检测AP | 分割AP | caption BLEU/CIDEr | COCO图找文/文找图 |
|---|---:|---:|---:|---|---|
| v2 Base | 86.3 | 58.6 | 50.6 | 35.4 /116.9 | 71.8/55.6 |
| v2 Large | 87.2 | 61.9 | 53.6 | 36.5 /122.5 | 75.0/58.5 |

Acc=准确率；AP=平均精度，检测框与分割 mask 的 AP 不能混用；R@1 是首个候选命中率；BLEU/CIDEr 是描述指标，不是正确率百分比。

v2 Large 相比 MoE Large 分类83.4→87.2（+3.8）；COCO图找文67.9→75.0（+7.1）。Flickr图找文89.3与 Flamingo-3B 相同，不是严格超过。图 2 的专用模型仍有更高结果：检测DINO62.4>61.9、分割MaskDINO54.5>53.6、ALIGN COCO检索77.0/59.9>75.0/58.5。

此处还改变了预训练骨干、模型结构与数据过程，不足以证明某个单模块解释全部增益。跨模态部署参数 Base308M、Large446M，不应拿视觉专用激活参数与此列直接比。

## 13. 资源与复现可行性

共享 decoder 6 层，所有 FFN 使用属性 MoE、每层 8 专家；不启用 LayerScale。学习率1e-4，weight decay1e-4，已预训练模态编码器学习率乘0.1。Swin Base/Large 分别32/64张A100、200k步；ResNet50 16张A100、150k步。

初学者适合先理解区域/全局形状、候选分类和规范化梯度的数值例子。完整论文训练不是单卡小实验。当前未找到确认的 v2 官方完整实现，因此不能假装下载原版仓库就已准备好运行 v2。

## 15. 学习优先级与状态

必须掌握：全局/区域、语义/框/mask、候选相似度、联合训练后评价的含义。

第二遍：区域提案筛选、detach、MT-AdamW采样补偿、消融差异和参数比较。

可以暂缓：deformable attention 底层 CUDA、去噪查询、完整定位匹配损失、多机训练。

**复现状态：未复现。** 完成论文主要方法、公式形状、实验与附录阅读；当前没有确认的 v2 完整代码及真实运行日志。没有用教学替代代码或原版程序冒充本篇官方实现。

未解决事项：定位网络实际发布源码；MT-AdamW零梯度/偏差修正实现；本地 v1 与后续版本差异；表3 caption括号差异；真实权重与任务评估；翻译全文审校。
