# ViLT / ALBEF：真实仓库和数据集

先说明关系：前面的 `vilt_tiny.py` 与 `albef_tiny.py` 是**从零训练核心结构的教学代码**。完整论文代码已有官方仓库，而且就在当前工作区：[ViLT 原仓库](../ViLT)、[ALBEF 原仓库](../ALBEF)。这些原仓库和我们的教学代码不是同一套运行环境，也不能直接共用模型权重。

## 1. 官方仓库

| 项目 | 在线地址 | 本地位置 | 重点 |
|---|---|---|---|
| ViLT | [dandelin/ViLT](https://github.com/dandelin/ViLT) | [ViLT](../ViLT) | README 提供预训练权重、VQA 演示、检索任务；[DATA.md](https://github.com/dandelin/ViLT/blob/master/DATA.md) 说明各数据集整理方式 |
| ALBEF | [salesforce/ALBEF](https://github.com/salesforce/ALBEF) | [ALBEF](../ALBEF) | README 提供预训练与下游任务权重；支持用图片路径和 caption 组成的 JSON 自定义数据 |

## 2. 数据集怎么选？

| 数据集 | 用途 | 大致规模 | 对初学者的建议 |
|---|---|---|---|
| [Flickr8k 镜像](https://huggingface.co/datasets/jxie/flickr8k) | 图文匹配、检索、图片描述 | 6000 张训练、1000 张验证、1000 张测试；每图 5 条描述 | **先取 64～500 张检查数据流程**，之后再扩大 |
| [Flickr30k](https://bryanplummer.com/Flickr30kEntities/) | 与 ViLT / ALBEF 官方检索任务更接近 | 约 3 万张图片 | 完成 Flickr8k 后再用；官方 ViLT 文档要求填写图片申请表 |
| [COCO Captions](https://cocodataset.org/#download) | 图文预训练与检索 | 远大于 Flickr8k | 初学阶段只取小部分，完整图片集较大 |
| [VQAv2](https://visualqa.org/download.html) | ViLT 的视觉问答任务 | 需问题、答案和 COCO 图片 | 已理解图文匹配后再尝试 |

ViLT 官方数据文档还列出 GCC、SBU、Visual Genome、NLVR2，并说明因授权问题不重新分发原数据。Flickr8k 这里给的是第三方镜像；数据页的元信息不等于原图片版权许可，公开发布训练数据或模型时仍要核对原数据条款。

## 3. 下载一个可读的小样本

脚本调用 Windows 自带的 `curl.exe` 下载数据，使用 Pillow 处理图片。若缺少 Pillow，请执行：

```powershell
py -3.13 -m pip install pillow
```

回到 `多模态` 目录，运行带逐行注释的 [下载脚本](下载Flickr8k样本.py)：

```powershell
py -3.13 小型复现/下载Flickr8k样本.py
```

程序会在 `小型复现/real_data/flickr8k-mini/` 保存 JPEG 图片，以及 `train.json`、`validation.json`。每条 JSON 记录长这样：

```json
{
  "image": "train/00000.jpg",
  "captions": ["第一条英文描述", "第二条英文描述", "第三条英文描述", "第四条英文描述", "第五条英文描述"]
}
```

脚本默认取 64 张训练图、16 张验证图；当前工作区已经保存这份样本。想先试更小规模，可加 `--train 20 --validation 4`。脚本使用 [Hugging Face Dataset Viewer 的 `/rows` API](https://huggingface.co/docs/dataset-viewer/rows)，每次最多取 100 行，再逐张保存图片。不会预先下载完整 Flickr8k，但运行时必须联网，接口中的图片链接有时效性；若网络连接失败，可以重新运行命令，已保存的图片会继续使用。

最初的 `vilt_tiny.py`、`albef_tiny.py` 入口使用红/蓝、方/圆的合成数据；真实 Flickr8k 请运行 [真实数据小训练.py](真实数据小训练.py)。它借助 [flickr8k_data.py](flickr8k_data.py) 建立英文词表，将图片缩为 64×64，再调用同一教学模型训练。这只是小样本教学实验，不能当作论文的完整复现；详细结果见 [真实数据训练.md](真实数据训练.md)。
